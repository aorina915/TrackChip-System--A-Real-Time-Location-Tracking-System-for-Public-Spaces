## ⚠️ TROUBLESHOOTING (If something goes wrong)

| Problem | Quick Fix |
|---------|-----------|
| Entity isn't moving | Backend may have stopped. Quick restart: `node index.js` in server folder |
| Map won't load | Clear browser cache or try incognito mode |
| Geofence not appearing | Ensure entity is within map bounds being viewed |
| Slow performance | Zoom in on map to reduce number of markers displayed |
| Login fails | Check credentials: `admin` / `trackchip123` |
| Can't record screen | Check browser permissions for Google Vids |

## 💡 PRO TIPS

1. **Practice the sequence once** before final recording
2. **Speak slowly and clearly** — examiners will appreciate it
3. **Point and explain** what you're doing as you do it
4. **Keep demo steps short** — demonstrate quickly, don't let system wait
5. **Have a backup story** if a feature doesn't work as expected
6. **Use pauses effectively** between sentences for clarity
7. **Avoid jargon** when possible; explain technical terms
8. **Keep eyes toward camera** during introduction and conclusion
9. **Smile and sound confident** — you know your project!
10. **Record in a quiet room** with good lighting
